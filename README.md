# Employee Salary Management System

## 📌 Overview
The **Employee Salary Management System** is designed for ACME Org’s HR team to replace manual Excel-based salary management.  
It enables HR managers to manage salary data for 10,000 employees across multiple countries, with reporting and audit capabilities.

---

## 🎯 Goal
- Provide a web-based solution for HR managers.
- Manage employee and salary records efficiently.
- Generate insights into how the organization pays people.
- Ensure audit logging for salary changes.

---

## 🏗️ Tech Stack
- **Backend:** Java 21, Spring Boot (microservice architecture)
- **Database:** MySQL
- **Frontend:** Angular 21, Tailwind CSS
- **Deployment:** Docker, Docker Compose
- **Testing:** JUnit (backend), Jest/Cypress (frontend)
