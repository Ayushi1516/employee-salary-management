# 🎨 UI Flow – HR Role

## HR Login
- Secure login page → HR Manager authentication.

---

## Dashboard
- Charts:
  - Average salary by department/country.
  - Highest salary.
  - Total employees.
- Quick stats cards.

---

## Employees
- Table view with:
  - Pagination
  - Sorting
  - Filtering
  - Global search bar
- “Add New Employee” option
- Row click → Navigate to full profile page:
  - Editable fields (name, department, country, hire date)
  - File upload (PDF/Excel for bulk updates)
  - Save changes → triggers audit log

---

## Salary
- Department‑wise salary breakdown
- Country‑wise salary breakdown
- Total employees per department/country
- Currency display
- Reporting dashboard with charts
